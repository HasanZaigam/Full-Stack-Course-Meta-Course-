In the next course, you’ll learn about APIs. API is an acronym that stands for Application Programming Interface and it connects two or more computer programs so that they can communicate with each other.

You’ll learn about the processes and concepts behind APIs and their infrastructure. Here, you’ll explore RESTful API development and specifically use the Django REST framework to create APIs efficiently. You’ll also learn to serialize your database models, sanitize data and implement search, ordering, filtering and pagination. Finally, you’ll discover advanced API development where you’ll learn to control access to your APIs and put systems in place to ensure you maintain their health.
