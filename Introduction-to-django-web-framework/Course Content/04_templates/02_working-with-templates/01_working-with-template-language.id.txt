Persyaratan umum saat membuat aplikasi web adalah kebutuhan untuk menambahkan data dinamis di dalam markup HTML. Data ini dapat diwakili oleh variabel yang berisi nilai dinamis atau dihitung atau nilai yang disimpan dalam database aplikasi. Bagaimanapun, kerangka kerja web membutuhkan cara untuk memahami data ini. Untuk mengatasi hal ini, Django menggunakan bahasa template Django atau DTL untuk memisahkan presentasi dan logika aplikasi. Dalam video ini, Anda akan belajar cara bekerja dengan bahasa template Django. Seperti yang Anda pelajari sebelumnya, template Django adalah string Python atau dokumen teks yang ditandai menggunakan bahasa template Django dan ditafsirkan oleh mesin template. DTL didasarkan pada mesin template Jinja2 yang populer, dan memiliki sebagian besar fitur umum untuk itu. Sebagai pengembang, menulis kode dalam bahasa yang akrab bermanfaat. DTL membantu menghilangkan penghalang itu dengan memberikan fleksibilitas yang selaras dengan prinsip penghematan waktu inti di Django yaitu jangan ulangi diri sendiri atau DRY. Ini juga menambahkan lapisan keamanan karena pener jemah Python tidak mengeksekusi kode template. Setelah Anda memahami penggunaan bahasa template, banyak logika dalam membuat template menjadi jelas. Ada empat konstruksi utama dalam sintaks DTL. Mereka adalah variabel, tag, filter, dan komentar. Dikombinasikan, mereka menyediakan pengganti fungsi dasar yang ada dalam bahasa pemrograman. Mari kita jelajahi masing-masing sekarang dengan sedikit lebih detail dimulai dengan variabel. Variabel dikelilingi oleh kurung kurung ganda. Ketika mesin template menemukan variabel, ia mengevaluasi variabel itu dan menggantinya dengan hasilnya. Variabel mengembalikan objek seperti kamus yang memetakan kunci ke nilai. Dalam contoh ini, nama restoran adalah kunci dengan nilai Little Lemon. Saat dirender, kode template ini menampilkan Selamat datang di restoran Little Lemon. Demikian pula, Anda dapat menggunakan pencarian indeks kamus, atribut, dan daftar menggunakan.notation. Sekarang Anda tahu tentang variabel. Mari beralih ke tag. Tag adalah sumber logika yang dapat Anda tambahkan ke template. Tag dibuat menggunakan kurung kur ung keriting dan simbol persentase. Tag yang paling umum digunakan adalah struktur kontrol seperti if dan for loop. Tag if digunakan di dalam template untuk merender output yang berbeda. Kasus penggunaan yang khas adalah memeriksa status login pengguna. Kode dalam contoh ini memeriksa apakah nilai variabel Boolean yang masuk adalah benar atau salah. Jika benar, halaman akan menampilkan pernyataan selamat datang. Jika salah, itu akan membuat tautan login. Alur kerja standar lainnya adalah mengulangi kam us untuk menampilkan daftar yang tidak berurutan. Untuk melakukan ini menggunakan template, Anda perlu memiliki beberapa cara untuk mengulang data dan mencetak markup HTML dengan objek data untuk setiap item dalam daftar. Sekarang mari kita pahami bagaimana daftar template dengan loop for bekerja. Misalnya, Anda memiliki daftar sederhana yang berisi item menu untuk restoran. Setiap item memiliki nama dan harga. Untuk membuat menu ini secara statis, Anda membungkus setiap item menu dalam daftar yang tidak berurutan menggunakan tag item daftar. Untuk membuat Menu ini secara dinamis dengan template, Anda menambahkan kode for loop di mana item berulang. Dalam contoh menu ini, itu ada di dalam daftar yang tidak berurutan. Kode akan berulang di atas objek daftar menu dan menampilkan nama dan harga. I@@ tem variabel akan menyimpan referensi ke setiap objek saat iterasi terus melewati setiap item menu. Terlepas dari jika dan untuk, ada banyak teks lain seperti memperluas dan memasukkan, dan Anda akan mempelajarinya nanti dalam pelajaran ini. Sekarang, mari kita jelajahi filter. Tidak seperti tag, filter dapat mengubah nilai variabel. Misalnya, jika Anda menambahkan filter seperti string atas, itu akan mengambil string input dan mengubahnya menjadi huruf besar. Filter juga dapat mengambil argumen seperti saat menggunakan filter tanggal. Misalnya, Anda dapat meneruskan argumen untuk tahun, bulan, dan hari, yang menghasilkan tanggal dalam format yang tepat ini. Akhirnya, mari kita jelajahi komentar. Anda dapat membuat komentar menggunakan tanda kur ung keriting dan simbol persentase. Django mengabaikan semua yang ada di antara dua tag.
